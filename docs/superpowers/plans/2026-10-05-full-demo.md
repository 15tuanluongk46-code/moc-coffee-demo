# MỘC Coffee full demo — Implementation Plan

**Goal:** Complete the approved four-chapter local coffee journey without additional review gates.
**Architecture:** One isolated Blender world with four stations and two baked camera tracks. Render a continuous video for each aspect ratio. A dependency-free static site maps native scrolling to video time and accessible HTML chapter content.
**Tech stack:** Blender, FFmpeg, HTML/CSS/JavaScript, Python standard-library local server; Playwright browser validation.
**Spec:** `docs/design.md`

## Constraints
- Free/open-source tools only; no paid generation or assets.
- Preserve existing farm proof and unrelated live Blender scenes.
- Original geometry; external assets require source/license records.
- Vietnamese UI, keyboard navigation, reduced-motion and failed-media posters.
- No commits or publishing requested.

## Tasks and interfaces
1. `scripts/journey_scene.py`: reuse farm geometry in a new scene; build roaster, espresso counter, ceramic cup and coffee bag. `build()` produces `MOC - Complete Journey`; `camera_tracks()` bakes cameras for frames 1–288 at 24 fps. Export `source/moc-journey-v01.blend`.
2. `scripts/render_journey.py`: consume the isolated blend, accept desktop/mobile and frame range; produce numbered PNGs. `scripts/package_media.py` verifies the complete sequence, invokes FFmpeg H.264 with short GOP and faststart, outputs `web/media/journey-{view}.mp4` plus four WebP posters and a media manifest.
3. `web/index.html`, `web/style.css`, `web/app.js`: editorial MỘC branding, fixed render stage, native scroll chapter stops, chapter navigation, progress, functional tasting-notes dialog and replay. Load only matching aspect ratio; coalesce video seeks; switch posters with no video fetch under reduced motion.
4. `scripts/serve.py`: loopback-only static server with byte-range media support; optional port. `scripts/test_web.py`: verify chapter navigation, forward/reverse seeks, fast scroll, narrow screens, reduced motion, forced-media error, dialog and console errors. Record output in `docs/validation-full.md`.

## Acceptance
All four chapters are visible, the same camera motion runs forward/reverse without joins, the site remains readable without video, and desktop/mobile browser tests pass. Deliver actual render dimensions and limitations rather than claiming equivalence to the TikTok reference.
